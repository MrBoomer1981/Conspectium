Перед тобой расшифровка страниц рукописного конспекта. Она уже
проверена: текст верный, числа верные, ошибки автора оставлены как есть.

Оформи её. Не переписывай, не дополняй, не объясняй — размечай.

ПРАВИЛА

1. Ни одного числа не меняй: ни запятую на точку, ни округление,
   ни «исправление» арифметики. Число — неприкосновенно.
2. Пометку [неразборчиво] оставь на месте, где она стоит.
   Не заполняй её и не убирай.
3. Слов не добавляй, кроме подзаголовков из правила 6.
   Своего текста не пиши: ни вступления, ни вывода, ни пояснения,
   ни «о чём эта тема».
4. Ошибку автора не трогай — ни в вычислении, ни в формулировке.
5. Структура: заголовок страницы — #, разделы — ##.
   Определяемый термин — **жирным**.
   Формула, стоящая отдельной строкой, остаётся отдельной строкой.
6. Определение, теорему, пример, следствие, доказательство помечай
   подзаголовком ### с этим словом.
7. Строку, продолжающую начатое предложение, присоединяй к предыдущей.
   Новый абзац — там, где начата новая мысль.
8. Маркированный список ставь только там, где список уже есть по смыслу.
   Обычную фразу списком не делай.
9. Записи вида [граф: 1-2, 2->3] и [схема: ...] оставь дословно —
   их рисует код, а не ты.
10. Разделитель --- между страницами сохрани.

ОТВЕТ — только размеченный markdown. Без пояснений, без ```-ограды,
без JSON.
